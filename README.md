# niemoli-voice-dataset

《纸嫁衣》聂莫黎语音素材与 **GPU 训练数据集**。素材从官方安卓 APK 内直接提取，经逐文件质检与可用性审查后整理。

## 两个 Release

| Tag | 内容 | 体积 | 用途 |
| --- | --- | --- | --- |
| `v1.0` | 最初爬取的 B 站 / 爱Pia戏 17 份素材（211 分钟） | 1.27 GB / 14 分卷 | 原始留档，混 BGM 与解说，需 UVR5-MDX 分离 |
| **`v2.0-clean`** | **游戏原声提取 + 质检后的干净训练集** | **848 MB / 10 分卷** | **GPU 训练用，推荐** |

`v2.0-clean` 包含：A 类 1349 条可用 WAV（高音质 382 / 普通音质 967）、分组试听 36 条、审查报告/看板/逐文件判定清单，以及 `gpu_train/` 一键脚本。**不含**已判定「需处理 / 不能用」的短音效 169、BGM 31、质检异常 17、长剧情 4 与上一批混音素材 17。

## GPU 服务器上三步开训

```bash
git clone https://github.com/ceshi3hao/niemoli-voice-dataset.git
cd niemoli-voice-dataset
bash gpu_train/bootstrap.sh                 # 从 Release 拉分卷 → 还原 → sha256 校验 → 解压
python3 gpu_train/prepare_dataset.py        # 响度归一化 + 长句切分 → dataset_ready/
cat gpu_train/train_params.md               # GPT-SoVITS 推荐参数
```

`bootstrap.sh` 优先用已登录的 `gh release download`，未登录时走公开 API + curl，无需 token。

## ⚠️ 开训前必做

**全部 1349 条都没有角色标注**（APK 内音频只有 hash 名，台词脚本属于运行时热更新资源）。必须先试听 `分组试听/` 锁定聂莫黎。注意 `素材可用性清单.csv` 的 `声纹组` 是按游戏代际聚的、**不是按说话人**（已验证：各组最大代占比加权 66%），只能当粗筛线索。

另一个坑：**聂莫黎与聂莫琪由同一配音演员（赵欣 / 朔小兔）演绎**，声线几乎一样，只能靠语气区分（黎姐冷、狠、算计、癫狂；莫琪暖、软、慌张），混进莫琪会污染音色。

## 数据审查结论摘要

见 `DATASET.md`。核心：真正能直接炼丹的只有 **382 条 / 38.8 分钟**（几乎全在《纸嫁衣4》），另外 967 条格式干净但有效带宽仅 8kHz；纸5/6/7/8/9 的语音是运行时热更新，APK 里 0 条。

## 许可

素材来自商业游戏录音与声优表演，非商业个人研究可用；商用前须取得游戏方与配音演员赵欣本人的许可。
